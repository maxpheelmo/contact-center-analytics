# SQL

Две папки:

- `views/`: витрины слоя mart. Это копии файлов из `py/views/`. Именно их подхватывает `wfm_store.py` при подключении к DuckDB (читает `py/views/`). Если правите витрину, держите обе папки одинаковыми.
- `analytics/`: примеры аналитических запросов поверх этих витрин и сырых таблиц. Они не входят в пайплайн, а показывают, как я считаю KPI, сравниваю периоды, строю воронку, ранжирую операторов и проверяю качество данных.

Запросы написаны на общем подмножестве DuckDB / PostgreSQL и прогнаны на синтетических данных из `sample_data/`.

Как выполнить все примеры (после `python py/load_sample.py`):

```bash
python sql/analytics/run_examples.py
```

Скрипт печатает результат в консоль и обновляет `docs/analytics_queries.md`.
